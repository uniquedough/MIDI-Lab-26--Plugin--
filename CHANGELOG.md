# Changelog

## 1.0.0 — 2026-11-25

- First ChatGPT plugin package of the complete MIDI Lab 4.2 codebase.
- Bundled existing 3.0, 4.0, 4.1, and 4.2 engines unchanged under `engine/`.
- Added a portable Agent Plugins 1.0 manifest and a local stdio MCP configuration.
- Added five MIDI tool operations with safe local output naming, input validation and program/bank event scans.
- Added composition skill, installation guides, examples, architecture description, tests, and GitHub release automation.
- Audio rendering and speculative 4.3 effect-aware composition are out of scope.
