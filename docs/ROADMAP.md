# Roadmap

## Shipped in this plugin

- Composer v3 original multi-profile compositions
- v4 emotional arcs, immutable/phase/microevolution loop modes
- v4.1 removable bliss/fracture textures and polymetric percussion
- v4.2 track-aware Effects Advisor (post-composition, read-only)
- ChatGPT packaging, local MCP protocol and plugin integration tests

## Proposed next

- **4.3 Sound-First Composition**: compose around anticipated delay repeats, reverb tail lengths, rhythmic masking and stereo space; **not yet implemented**.
- **4.4 Variations**: alternate MIDI instrument parts with one invariant motif.
- **4.5 Song DNA**: learning from approved user material (opt-in).
- **5.0 Audio Critique**: analyze optional rendered WAV files in addition to symbolic MIDI.

These are proposals, not claims about current capabilities.
