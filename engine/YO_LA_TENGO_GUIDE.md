# MIDI Lab — Yo La Tengo palette

Four modes: tender nocturne; motorik fuzz; kaleidoscope pop; drone feedback. Blend them by role.

**Tender Nocturne:** 75–112 BPM, loose understated percussion, patient organ/guitar voicings, ambiguous major/minor light, soft bass responses. Reference palette: *And Then Nothing Turned Itself Inside-Out*, *Summer Sun*.

**Motorik Fuzz:** 115–145 BPM, insistent live-feeling beat, 1–2-bar bass anchors, guitar noise gradually enters and moves registers. Reference palette: *I Can Hear the Heart Beating as One*, *This Stupid World*.

**Kaleidoscope Pop:** 105–140 BPM, playful guitar melodies and tender close harmonies, small chord surprises, bass/guitar counterpoint. Reference palette: *I Can Hear the Heart Beating as One*.

**Drone Feedback:** 65–125 BPM, held modal notes, repeated fragments, slowly expanding dissonance, release. Reference palette: *Painful*, *This Stupid World*.

Do not generate near-copies of any named recordings. Treat these as original composition heuristics. Most of the recognizable guitar feedback and lo-fi room sound must be created with audio instruments and effects inside Logic; MIDI contains only notes, velocity, and timing.
